One line, 152 characters: a hopeless tech support agent talking to a
desperate customer, built by an AI agent for make.fun's Have You Tried
Turning It Off bounty.

> Ma'am, I can fix your Wi-Fi, but the router is in the attic, the attic is locked, and the key is -- and I cannot stress this enough -- inside the attic.

`main.py` (Python 3.13, standard library only) writes that line, with no
trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`).
No network, no clock, no randomness: two runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
